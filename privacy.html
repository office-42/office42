Privacy

Last updated: September 4, 2026

Office42, the program

Office42 Spreadsheet is free software, licensed under the GPL, that runs entirely on your own computer.

  • Office42 collects no personal data.
  • Office42 does not send your books, your cells or anything else over the network. It has no telemetry, no analytics, no crash reporting and no update checks, and no networking code at all.
  • Your books stay on your computer, in files you control. A SQLite database kept beside a book or inside it is a file on your disk like any other.
  • A hyperlink in a cell opens in your browser only when you click it. A book that arrives with Python scripts offers to run them and never runs them by itself; what a script you choose to run does is up to the script.

office42.net, the website

This website is a set of static pages with no cookies, no analytics and no tracking, and it loads nothing from third-party servers: every page, stylesheet and image is served from office42.net itself. It is hosted on GitHub Pages, and GitHub may record basic technical information about visits, such as IP addresses, in its server logs, as described in the GitHub Privacy Statement. We do not receive or store any of that information ourselves.
